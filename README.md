## 📊 What I've Built

### 🔍 Revenue Reconciliation Engine — Calyxra
End-to-end analytics platform that cross-matches transaction data from Shopify, Meta Ads, Google Ads, and TikTok to detect phantom revenue — money reported by ad platforms that never actually arrives.

- **ETL Pipelines** — Python scripts pulling data from 4+ APIs into BigQuery daily
- **SQL Models** — CTEs, Window Functions, and complex JOINs reconciling thousands of transactions
- **Power BI Dashboards** — Automated KPI reporting (ROAS, CAC, LTV) with scheduled refresh
- **Impact** — Regularly uncovers 5-15% revenue discrepancies for e-commerce clients

### 📈 E-Commerce Cohort Analysis
Full analytics workflow for customer retention and LTV calculation using Python, SQL, and Power BI.

- Processed 500K+ transactional rows
- Built cohort retention matrices with Window Functions
- Created interactive Power BI dashboards with DAX measures
